# ข้อตกลงที่ต้องกำหนดก่อนแยกเขียนระบบ

เอกสารนี้เป็นรายการตัดสินใจร่วมกัน ยังไม่ได้สร้าง API หรือ implementation ของระบบเกม

## Pai: world

- Node: รหัสที่ไม่ซ้ำ พิกัดที่ทีมใช้ร่วมกัน และข้อมูลจุดกิจกรรม
- Edge: รหัส จุดต้น/ปลาย ทิศทาง ต้นทุน ประเภทเส้น และข้อมูลเฉพาะที่จำเป็น
- Graph: การอ่านโหนด เส้น เพื่อนบ้าน และการตรวจเส้นที่เดินได้
- Player/MoveRecord: ตำแหน่งและประวัติการเดินจริง
- ระบุว่าจะยืนยันการเดินสำเร็จและรีเซ็ตผ่านเมธอดใด

## Book: game

- Level: ข้อมูลด่าน L01–L15, กราฟ, จุดเริ่ม, เป้าหมาย, ทรัพยากร, กิจกรรม, กติกา และรหัสบทเรียน
- GameSession: ช่องทางรับคำสั่งเริ่ม เดิน ทำกิจกรรม ส่งภารกิจ เริ่มใหม่ และเปลี่ยนด่าน
- MissionResult: ผลตรวจพร้อมเหตุผลที่ UI แสดงได้
- ข้อมูลสถานะสำหรับ UI: ตำแหน่ง ทรัพยากร ความคืบหน้า ปุ่มที่กดได้ และข้อความล่าสุด
- ตกลงจังหวะอนุมัติเดิน หักทรัพยากร ยืนยันว่าเดินจบ และยกเลิกแอนิเมชันเมื่อรีเซ็ต ให้เกิดการเปลี่ยนสถานะเพียงครั้งเดียว

## Dream: ui

- รับข้อมูลจากระบบเกมและแสดงผล โดยไม่เก็บกติกาผ่านหรือทรัพยากรอีกชุดใน UI
- ส่งรหัสโหนด/เส้นและคำสั่งกิจกรรมให้ GameSession
- แจ้งเมื่อแอนิเมชันเดินจบ และหยุดแอนิเมชันรอบเก่าเมื่อเริ่มใหม่
- ตกลงวิธีรับขั้นตอนบทเรียนและเรียกขั้นถัดไป/เริ่มสาธิตใหม่

## Korn: algorithm และ lesson

- อัลกอริทึมแต่ละประเภทรับข้อมูลตามโจทย์ที่รองรับ ไม่จำเป็นต้องรับพารามิเตอร์เหมือนกันทั้งหมด
- ผลอ้างอิงสำหรับตรวจภารกิจแยกจากข้อมูลแสดงการสาธิต
- AlgorithmStep: ลำดับขั้น ข้อความ โหนด/เส้นที่ไฮไลต์ และค่าคำนวณที่ต้องแสดง
- แต่ละขั้นเก็บสถานะของตัวเอง ไม่แชร์ข้อมูล mutable ที่ทำให้ทุกขั้นเปลี่ยนตามขั้นสุดท้าย
- อ่านกราฟเพื่อคำนวณโดยไม่เปลี่ยนตำแหน่ง ทรัพยากร หรือประวัติการเล่น

## การส่งงาน

ส่งชื่อคลาส ชื่อเมธอด ข้อมูลเข้า ผลลัพธ์ และตัวอย่างเรียกใช้ตั้งแต่เริ่ม เปลี่ยนข้อตกลงที่ผู้อื่นใช้อยู่ให้แจ้งก่อน ส่งข้อมูลและรวมงานทีละ 1–3 ด่าน
