# แนวคิดเกมที่ยึดร่วมกัน

- ชื่อเกม Tour de Lost ใช้ Java 2D มุมมองจากด้านบน
- ขอบเขตเป้าหมาย 15 ด่าน เมืองหรือประเทศเปลี่ยนได้ตามด่าน
- ผู้เล่นรับบทผู้ดูแลเมือง ทำภารกิจ เช่น ส่งยา สำรวจ เติมน้ำมัน วางสายไฟ และประปา ตามรายการด่านที่ทีมกำหนด
- ฉากจัดวางด้วย Grid แต่การเดินและกิจกรรมอิงโหนดกับเส้นเชื่อม
- ถนนหนึ่งเส้นวาดผ่านหลายช่องได้ จำนวนช่องไม่กำหนดต้นทุน ให้ใช้ค่าของเส้น
- ผู้เล่นคลิกโหนดที่เชื่อมโดยตรง เลือกครั้งละหนึ่งจุด และรอเดินจบก่อนออกคำสั่งถัดไป
- เส้นมีลูกศรใช้ตามทิศ เส้นไม่มีลูกศรใช้สองทิศ การย้อนกลับเสียทรัพยากรตามปกติ
- กิจกรรมที่โหนดต้องอยู่ในจุดนั้น การก่อสร้างบนเส้นต้องอยู่ที่ปลายเส้นด้านใดด้านหนึ่งตามกติกาด่าน
- แต่ละด่านใช้เฉพาะทรัพยากรที่เกี่ยวข้อง
- ก่อนเริ่มให้ดูโจทย์และแมพได้โดยยังไม่เสียทรัพยากร บางด่านซ่อนข้อมูลตามเงื่อนไขการสำรวจ
- ผู้เล่นตัดสินใจเอง ไม่มีปุ่มเลือกอัลกอริทึมหรือเครื่องมือหาเส้นทางดีที่สุดให้ก่อนชนะ
- คำใบ้ก่อนชนะไม่เปิดเผยชื่ออัลกอริทึม
- ตรวจความสำเร็จก่อนความล้มเหลว ใช้ครบงบได้หากกติกาอนุญาต
- หากทรัพยากรไม่พอให้ปฏิเสธการกระทำนั้น หากยังมีกิจกรรมช่วยไปต่อได้ต้องไม่รีบตัดสินแพ้
- เริ่มใหม่คืนตำแหน่ง ทรัพยากร และสถานะทั้งหมด ไม่มีโทษสะสม
- หลังชนะจึงแสดงชื่อ หลักการ และการสาธิตอัลกอริทึมที่เกี่ยวข้อง
- อธิบายว่าอัลกอริทึมช่วยแก้โจทย์อย่างไร ไม่อ้างว่าผู้เล่นใช้อัลกอริทึมนั้นเพียงเพราะเลือกเส้นทางเดียวกัน
- ยอมรับคำตอบถูกหลายแบบตามเงื่อนไขจริง

## ข้อมูลด่านที่ต้องรวบรวม

แต่ละด่าน L01–L15 ต้องมี: ชื่อเมือง/ประเทศ, เรื่องราวและโจทย์, โหนด/เส้น/ทิศทาง/ต้นทุน, จุดเริ่ม/เป้าหมาย, ทรัพยากร, กิจกรรม, เงื่อนไขผ่าน/ไม่ผ่าน, ตัวอย่างวิธีผ่านที่ตรวจแล้ว, อัลกอริทึมและบทเรียนหลังชนะ

ยังไม่ได้เติมรายละเอียดหรือรายชื่ออัลกอริทึมของทั้ง 15 ด่านแทนทีม
